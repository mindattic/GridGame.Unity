Skill Hexagon

The same six stats on the corners, but the board is made of abilities, not heroes. Every ability sits where its stat needs put it, and every ability is ringed by stat passives, so you can always walk sideways. A hero is just the path it starts with: a snaking, sometimes branching trail through the abilities it joins with, ending at its own signature move. From there any hero can spec toward anything. Pick a hero, then click abilities to plan a build. Switch the mode to edit the board or a hero's start path, then save the board back over and run python tools/skillhex/sync.py so this page draws it. Inside the claude.ai viewer, where downloads are blocked, use Copy JSON and paste it over that file instead. The empty Open slots, and what should go in each, are listed in GAPS.md.
